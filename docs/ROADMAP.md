# Roadmap

This file is the plan of guidebook. The Status page of the site reads it, and the tracker of the project mirrors it.

| ID | Item | Status | Summary |
| --- | --- | --- | --- |
| R1 | The first package | done | Make the first package with `pnpm package add`. The core `@mark1russell7/guidebook` is the first package. |
| G1 | The core | done | Sources with their licenses, cited units (a quote, a summary or a fact), the rule of each license and the source gate. The core names no topic. |
| G2 | The plans add-on | done | The time ladder, steps keyed by a case or a cut and a phase, the steps query, the matrix of a library with marked gaps, and the step gate. |
| G3 | The steps of 12 cases and 6 cuts | done | A content package with the public steps of 12 cases and 6 cuts from `ready` to `P3`, an outline for `P4` and `P5`, and a marked gap in each empty cell. Each step cites a public source. |
| G4 | The first npm release | done | The 5 packages are on npm at `0.1.0`. Other repositories import them with a caret range. |
| G5 | The site demo | done | The site is a live demo: a plan for a case and its cuts, the matrix of the steps with a filter of the rows, and the findings of the gates. |
| G6 | The quote check | later | Compare each quote with the text of its source, through the quote check of `polite-crawler`, and set the date `checked`. |
| G7 | The coverage gate | done | Each key has steps in each horizon from 5 minutes to 5 years. A marked gap fails the gate. A test holds the list of the open cells, so it can only get shorter. |
| G8 | The steps of each supply part | done | Steps at each horizon for each part that an emergency can cut: power, water, sewer, gas, phone, internet, roads, fuel, food, cash, care and the home. |
| G9 | The plan for an AI-driven collapse | done | The steps of the case: loss of income, false information, attacks with new tools. Its cuts come from the hazard catalog. |
| G10 | The plans for the other catastrophic cases | done | Nuclear war and a detonation, a pandemic, a long grid-down, a cyberattack, a food supply failure, a financial collapse, civil unrest, war, an EMP and a solar storm. |
| G13 | The master chart | done | One chart for any disaster, as data: signals, then questions on the danger, the state of society and stay or go, then a tab. A gate holds that each hazard has a route. |
| G14 | The branch with no society | done | Each cut and the key `society.services` have steps for no emergency services, no shops, no grid and no law, from 5 days to 5 years, by need. Strategy steps give their reasoning. A number keeps its source. |
| G15 | The reference appendices | next | The appendices as cited units: water, food storage, first aid, sanitation, heat and cold, radio and other references. |
| G16 | No step that waits for officials | done | A gate refuses each step that tells the reader to obey, listen to or wait for officials. A broadcast is one source of information. |
| G17 | The master graph | done | One value `GRAPH` of the schema `guidebook-graph/2` for the binder and the app: the chart, the tabs and the hazard catalog. Each hazard row has signals, an entry node and a card of its own facts. A gate checks each row. |
| G18 | The red-team fixes of wave 1 | done | Question B splits: a danger inside the place sends the reader out, and a danger in the air or the street keeps the reader inside. Each end of the first questions leads on to society and the needs. The cards hold each step of the first 72 hours. Gates hold each fix. |
